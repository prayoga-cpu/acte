# Definition of done

A task is done when all of these are true:

- [ ] Schema in `packages/contracts` exists or is updated
- [ ] Typecheck, lint, tests pass in CI
- [ ] For UI: screenshot compared with the prototype, no visible difference
- [ ] For data: firm scoping tested; sensitive fields encrypted
- [ ] No P0 / P1 data in logs (see PRIVACY_MODEL)
- [ ] Deployed to staging
- [ ] `STATUS.md` ticked and log line added
- [ ] Any choice made is recorded in `DECISIONS.md`
